# Validation

CI resolves first-party main once and shares that exact lock across substantive
checks. Native and actual Chrome/Wasm execute the same Link vectors. Real Forum
registry refusal is not admission or network acceptance. Heavy load/churn runs
belong on owned CI.

Every emitted production source line and branch must be covered. The strict gate
uses upstream LLVM LCOV from the same execution as the retained JSON diagnostic.
There are no production exclusions. This measures source coverage, not separate
coverage of every generic instantiation. Executed fixtures live under tests/ and
are excluded from production metrics. JSON remains diagnostic because generic
instances can retain unvisited specializations of a line exercised elsewhere.

Dependabot covers the Cargo and workflow manifests. Metadata-only auto-merge
requires strict protected main including administrators, every substantive job,
all current-head checks/statuses, and an atomic head-SHA merge. It never executes
PR code under a privileged token.
